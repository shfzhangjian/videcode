# videcode

这里收录可直接体验的互动学习与创意编程项目。

## 项目目录

### 物理造物局：未来岛工程挑战

面向初中物理学习者的任务式互动知识库。学生不是按章节机械背诵，而是作为“未来岛工程师”，在预测、动手实验、解释规律和题目固化中完成挑战。

- 项目目录：[physics-quest-lab](./physics-quest-lab/)
- 在线体验：[https://shfzhangjian.github.io/videcode/](https://shfzhangjian.github.io/videcode/)
- 主要内容：6 个工程任务、22 个关键章节、8 组易混母题、变式训练与间隔复习
- 学习闭环：接任务 → 先预测 → 动手试 → 讲道理 → 题目固化 → 到期回练
- 学习记录：自动保存在当前浏览器中，不上传个人数据

网站由 GitHub Actions 自动发布：`main` 分支中 `physics-quest-lab/` 的更新会触发重新部署。

# 物理造物局｜未来岛工程挑战

这是一个零依赖、可直接运行的初中物理互动学习网站。它把知识点、动画实验、工程目标和题目训练串成一条完整学习路径。

## 学生怎么学

1. 接受一个未来岛工程任务，并先写下预测。
2. 调节实验参数，观察动画和数据反馈。
3. 用“主张—证据—规律”解释为什么。
4. 完成基础题、变式题和综合验收。
5. 在“易混母题”中辨析相近公式与概念，连续答对两道变式才算稳固。
6. 按 10 分钟、1 天、3 天的节奏回练，形成长期记忆。

## 内容结构

- `index.html`：页面结构与学习入口
- `styles.css`：视觉、动画和响应式布局
- `data.js`：22 章知识地图、题库、工程任务和易混母题
- `app.js`：互动实验、答题反馈、进度与间隔复习逻辑

无需安装依赖。直接打开 `index.html` 即可体验；也可以使用任意静态文件服务器预览。
